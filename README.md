## Screen Plan

After signing in, users can switch between the Home, Chores, Rewards, Family, and Profile tabs. Detail and form screens return to the screen that opened them when the user presses Back.

### Account screens

- **Login:** Lets a parent or child sign in; successful sign-in opens the main app, and new users can go to Choose Account Type.
- **Choose Account Type:** Lets a new user choose a parent or child account; continue to Register or return to Login.
- **Register:** Creates a parent or child account; after successful registration, the user enters the main app.

### Main app screens

- **Home / Dashboard:** Shows household progress, chores, approvals, and shortcuts; opens Chore Detail, Create / Edit Chore, Approvals, Missed Chores, Quick Cleanup, Family Member Profile, or Create / Edit Reward.
- **My Chores:** Shows the signed-in member’s assigned chores and their status; opens Chore Detail or Create / Edit Chore.
- **Rewards:** Shows available rewards and point balances; opens Create / Edit Reward or Active Privileges.
- **Family:** Shows household members and their availability; opens a Family Member Profile.
- **Profile:** Shows the user’s profile and activity; opens Edit Profile, Notification Settings, or Legal Information.

### Detail and management screens

- **Chore Detail:** Shows a chore’s instructions, points, due information, and completion details; can open Create / Edit Chore.
- **Create / Edit Chore:** Lets a parent create or update a chore and its assignment; returns to the screen that opened it.
- **Approvals:** Lets a parent review submitted chores and approve or reject them; returns to the screen that opened it.
- **Missed Chores:** Shows incomplete past chores and lets a parent reassign or dismiss them; returns to the screen that opened it.
- **Quick Cleanup (Home Reset):** Lets a parent choose household cleanup tasks and distribute them among family members; returns to Home.
- **Create / Edit Reward:** Lets a parent create or update a reward; returns to the screen that opened it.
- **Active Privileges:** Shows current and expired rewards that have been granted, with options to remove an active privilege; opened from Rewards.
- **Family Member Profile:** Shows a family member’s activity and privileges; opened from Home or Family.
- **Edit Profile:** Lets the user update their profile information; returns to Profile.
- **Notification Settings:** Lets the user manage notification preferences; opened from Profile.
- **Legal Information:** Displays the Privacy Policy, Terms of Use, and FAQs; opened from Profile.
