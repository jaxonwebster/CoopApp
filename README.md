# 🐔 Coop

**Coop** is a "coop"erative family-focused mobile app that helps households organize chores, earn points, and redeem rewards. Parents can manage chores and rewards, while kids can complete chores, earn points, and work toward privileges.

## ✨ Features

- **Parent and kid accounts**
- **Multiple parents in one household**
- Household invite codes
- Create, assign, edit, and complete chores
- Recurring chores with customizable days
- Optional parent approval
- Missed chore tracking
- Home Reset chores
- Points and rewards
- Shared family rewards
- Once-per-day and first-to-claim rewards
- Reward history and privileges
- Family and personal progress calendars
- Profile pictures
- Chore reminders
- Parent approval notifications

## 🛠️ Tech Stack

- **React Native**
- **Expo**
- **React Navigation**
- **Firebase Authentication**
- **Cloud Firestore**
- **Firebase Storage**
- **Firebase Cloud Functions**
- **Expo Notifications**
- **Expo Image Picker**
- **JavaScript**
